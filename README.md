# Student Score Calculator

A simple web application that calculates students' total scores and grades automatically.

### Features

* 5 students
* CA 1, CA 2, CA 3: maximum 10 each
* Exam: maximum 70
* Automatic total and grade calculation

### Technologies

* HTML
* CSS
* JavaScript

### Files

* `index.html`
* `style.css`
* `script.js`
